## 为什么选择 Hugo？

- **速度快**：Hugo 使用 Go 语言编写，构建速度极快
- **简洁**：使用 Markdown 写作，专注内容
- **灵活**：丰富的主题和模板系统
- **免费部署**：配合 GitHub Pages 或 Vercel 完全免费
